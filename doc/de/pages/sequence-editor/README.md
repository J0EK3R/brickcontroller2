# Sequenz-Editor

Eine Sequenz ist eine wiederverwendbare Reihe von Steuerpunkten. Beim Abspielen durchläuft die Ausgabe die Steuerpunkte nacheinander. So kannst du Bewegungen automatisieren, zum Beispiel ein Tor öffnen oder ein Bewegungsmuster abfahren.

## Sequenzeigenschaften

- **Name**: Tippe oben auf den Namen, um die Sequenz umzubenennen.
- **Wiederholen**: Ist diese Option aktiviert, beginnt die Sequenz nach dem letzten Steuerpunkt wieder von vorn.
- **Interpolieren**: Ist diese Option aktiviert, ändert sich der Wert zwischen den Steuerpunkten gleichmäßig. Andernfalls springt er direkt zum Wert des nächsten Steuerpunkts.

## Steuerpunkte

Jeder Steuerpunkt enthält:

- **Wert (%)**: Ausgabewert von -100 bis 100 in Schritten von 5. Negative Werte treiben den Kanal in die entgegengesetzte Richtung an.
- **Dauer (ms)**: Legt fest, wie lange dieser Steuerpunkt gilt. Tippe auf die Dauer, um sie zu ändern.

Tippe auf die schwebende **+**-Schaltfläche, um einen Steuerpunkt hinzuzufügen. Über die **x**-Schaltfläche in einer Zeile kannst du ihn löschen.

## Symbolleiste

- **Teilen**: Teile die Sequenz als Text.
- **Als Datei teilen**: Teile die Sequenz als Datei.
- **Kopieren** (Überlaufmenü): Kopiere die Sequenz in die Zwischenablage.
- **Exportieren** (Überlaufmenü): Exportiere die Sequenz in eine Datei.
- **Änderungen übernehmen**: Speichere die Sequenz und schließe den Editor.
- **Hilfe** (Überlaufmenü): Öffne diese Hilfeseite.
