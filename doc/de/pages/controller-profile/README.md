# Controller-Profil

Ein Controller-Profil ordnet Controller-Ereignisse (Tasten, Sticks und Trigger) Aktionen für deine Geräte zu.

## Ereignis hinzufügen

Du fügst ein Ereignis hinzu, indem du den Controller verwendest. Daher muss zuerst ein Gamecontroller (Gamepad) oder ein anderes Eingabegerät verbunden sein.

1. Verbinde den Controller und stelle sicher, dass sich mindestens ein Gerät in der Geräteliste befindet. Falls nicht, wirst du zuerst aufgefordert, nach Geräten zu suchen.
2. Tippe auf eine der Schaltflächen zum Hinzufügen:
   - **Neues Controller-Ereignis hinzufügen**: akzeptiert eine Taste oder einen Joystick.
   - **Neues Controller-Tastenereignis hinzufügen**: akzeptiert nur eine Taste.
   - **Neues Controller-Achsenereignis hinzufügen**: akzeptiert nur einen Joystick.
3. Drücke auf Aufforderung eine Taste oder bewege den Joystick am Controller. Die App verwendet die erste erkannte Eingabe.
4. Die Aktionsseite wird geöffnet, auf der du das Verhalten des Ereignisses einrichtest.

Du kannst den Dialog abbrechen, wenn keine Eingabe erkannt wird.

## Mehrere Controller

Standardmäßig reagiert ein Ereignis auf die gewählte Taste oder den Joystick jedes verbundenen Controllers.

Wenn mehrere Eingabegeräte verbunden sind, verwende **Neues Controller-Ereignis für einen bestimmten Gamecontroller hinzufügen**. Das Ereignis wird dann an den verwendeten Controller gebunden, der zum Beispiel als „Controller 1“ angezeigt wird. Andere Controller lösen es nicht aus. So können zwei Controller mit denselben Tasten unterschiedliche Geräte steuern.

Für verschiedene Controller kannst du separate Ereignisse mit derselben Taste oder demselben Joystick erstellen.

## Möglichkeiten

- Füge einem Controller-Ereignis eine Aktion hinzu.
- Bearbeite oder lösche bestehende Aktionen.
- Teste das Profil mit dem Controller-Tester.

## Tipps

- Ein Ereignis kann mehrere Aktionen auf verschiedenen Geräten steuern.
