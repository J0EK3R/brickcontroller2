# Geräte

In der Geräteliste findest du die Geräte, die du in Modellen verwenden kannst.

## Gerät hinzufügen

Es gibt zwei Möglichkeiten, ein Gerät hinzuzufügen.

### Erkannte Geräte

Die meisten Geräte werden bei einer Suche erkannt.

1. Schalte das Gerät ein.
2. Tippe auf **Nach neuen Geräten suchen**.
3. Erkannte Geräte werden zur Liste hinzugefügt.

### Manuell hinzugefügte Geräte

Einige Geräte können bei einer Suche nicht erkannt werden. Sie verbinden sich nicht mit der App, sondern werden über Bluetooth-Werbenachrichten gesteuert. Daher gibt es nichts, wonach gesucht werden könnte.

1. Tippe auf **Geräte manuell hinzufügen**.
2. Wähle die hinzuzufügenden Geräte aus. Entferne die Auswahl eines Geräts, um es zu löschen.
3. Übernimm die Änderungen.

Das manuelle Hinzufügen ist nur verfügbar, wenn dein Smartphone Bluetooth-LE-Werbenachrichten unterstützt. Geräte, die andere Hardware benötigen, etwa Power-Functions-Infrarot, werden nur angeboten, wenn dein Smartphone diese Hardware unterstützt.

### Welche Methode soll ich verwenden?

| Durch Suche hinzufügen | Manuell hinzufügen |
|---|---|
| SBrick, SBrick Light, BuWizz 2 | |
| BuWizz, BuWizz 3 | Mould King MK3, MK3.8, MK4, MK5, MK6 |
| LEGO Boost, Powered Up, Technic Hub, Technic Move, Duplo Train Hub, WeDo 2.0, Remote Control | JIESTAR SCM4, SCM8 |
| Circuit Cubes | PowerBox M Battery, A Series |
| PFx Brick | Power Functions-Infrarot |
| Mould King MK DIY, CaDA Race Car | |
