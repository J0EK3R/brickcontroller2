# Sequenzen

Eine Sequenz ist eine wiederverwendbare Reihe von Steuerpunkten, mit der du den Ausgabewert eines Kanals automatisierst. Du kannst Sequenzen in einem Controller-Profil eines Modells Controller-Aktionen zuweisen.

## Möglichkeiten

- Füge mit der schwebenden **+**-Schaltfläche eine Sequenz hinzu.
- Tippe auf eine Sequenz, um sie im [Sequenz-Editor](../sequence-editor/README.md) zu öffnen.
- Wische bei einer Sequenz nach rechts, um sie zu **Teilen**.
- Wische bei einer Sequenz nach links, um sie zu **Löschen**.

## Symbolleiste

- **QR-Code scannen**: Importiere eine geteilte Sequenz, indem du ihren QR-Code scannst.
- **Aus Datei importieren**: Importiere eine Sequenz aus einer Datei.
- **Sequenz einfügen**: Füge eine in die Zwischenablage kopierte Sequenz ein.
- **Sequenz importieren** (Überlaufmenü): Importiere eine Sequenz aus Text.
- **Hilfe** (Überlaufmenü): Öffne diese Hilfeseite.
