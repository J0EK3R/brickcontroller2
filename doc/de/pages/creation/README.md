# Modell

Auf dieser Seite siehst du die Controller-Profile eines Modells.

## Möglichkeiten

- Füge Controller-Profile hinzu, benenne sie um, kopiere oder lösche sie.
- Öffne ein Profil, um seine Controller-Aktionen einzurichten.
- Starte das Modell, um es zu steuern.

## Tipps

- Verwende mehrere Profile, um zwischen Steuerungsschemata zu wechseln, zum Beispiel zwischen einer einfachen und einer detaillierten Steuerung.
