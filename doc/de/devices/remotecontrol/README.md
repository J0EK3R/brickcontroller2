# LEGO Powered Up Remote Control

Die LEGO Powered Up Remote Control (88010) ist eine Bluetooth-LE-Fernbedienung ohne Ausgänge. Sie dient als Eingabegerät; ihre Tasten kannst du Controller-Aktionen zuweisen.

![Remote Control](../../../../BrickController2/BrickController2/UI/Images/remotecontrol_image_small.png)

## Tasten

| Taste | Beschreibung |
|---|---|
| A, B | Mittlere Tasten auf der linken (A) und rechten (B) Seite |
| A.Plus, A.Minus | Plus- und Minustaste auf der linken Seite |
| B.Plus, B.Minus | Plus- und Minustaste auf der rechten Seite |
| Home | Grüne Taste |

## Erste Schritte

1. Schalte die Fernbedienung ein, indem du ihre grüne Taste drückst.
2. Öffne die Geräteliste und tippe auf **Nach neuen Geräten suchen**. Gefundene Geräte werden zur Liste hinzugefügt.
3. Öffne die Geräteseite und aktiviere die Fernbedienung. Standardmäßig ist sie deaktiviert.
4. Weise ihre Tasten Controller-Aktionen zu.

## Hinweise

- Die Fernbedienung hat keine Kanäle und kann daher in einem Modell nicht als Ausgabegerät verwendet werden.
