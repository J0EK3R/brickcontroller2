# BrickController 2 – Dokumentation

BrickController 2 ist eine plattformübergreifende App für Android, iOS und Windows, mit der du LEGO-Modelle und kompatible Modelle über einen Bluetooth-Controller steuerst.

## So funktioniert die App

1. **Geräte hinzufügen.** Geräte sind die Empfänger in deinem Modell, zum Beispiel Hubs, Bricks und Module. Die meisten findest du durch eine Suche, einige musst du manuell hinzufügen. Jedes Gerät besitzt Kanäle, etwa für Motoren oder Beleuchtung.
2. **Ein Modell erstellen.** Ein Modell steht für ein Fahrzeug oder eine Konstruktion und enthält alles, was du zum Steuern benötigst.
3. **Controller-Profile einrichten.** Ein Modell kann ein oder mehrere Controller-Profile enthalten, zum Beispiel für verschiedene Gamepads oder Fahrmodi.
4. **Controller-Aktionen zuweisen.** Eine Controller-Aktion ordnet eine Gamepad-Taste oder -Achse einem Gerätekanal zu. Einstellungen wie Richtung, Geschwindigkeit und Tastenverhalten legen fest, wie der Kanal reagiert.
5. **Losfahren.** Starte das Modell. Die App verbindet sich mit den Geräten und du steuerst das Modell mit dem Gamepad.

Sequenzen ergänzen zeitgesteuerte Ausgaben, zum Beispiel Lichteffekte, die eine Controller-Aktion starten kann.
